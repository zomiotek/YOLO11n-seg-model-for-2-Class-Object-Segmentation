# YOLO11n-seg model for 2-Class Object Segmentation
The shared script shows how to train and evaluate a YOLO model pre-trained on the COCO dataset. The dataset I prepared and used in this experiment can be downloaded from the Zenodo platform: https://doi.org/10.5281/zenodo.18702734. You can use the shared code for your own experiments with YOLO object segmentation models.
